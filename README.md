# DAOC Brightness

Windows용 독립 실행형 게임 화면 밝기 조절 도구입니다. `game.dll` 또는 `eden.dll`을 포함하는 32비트 프로세스를 찾아 DirectX 9 / 10 프레임에 색 보정을 적용합니다. 창 모드와 독점 전체 화면 모드를 지원하며, 바탕 화면 감마를 변경하지 않습니다.

앱을 시작할 때 Windows 표시 언어를 확인합니다. 한국어 표시 언어에서는 한글, 그 외 언어에서는 영어로 표시합니다. 버튼, 상태와 오류 메시지, 게임 안 메뉴에 동일하게 적용합니다. 키보드 입력 언어와 지역 형식 설정으로 선택하지 않습니다. Windows 표시 언어를 변경한 뒤에는 앱을 다시 실행하세요. 내장 DLL이 이미 게임에 연결된 상태라면 게임도 다시 실행해야 새 버전이 적용됩니다. 라이브러리의 라이선스 본문은 원문을 유지합니다.

번역 문구는 `UiStrings.rc`의 영어(0x0409)와 한국어(0x0412) `STRINGTABLE`에서 관리합니다. 문자열 ID는 `src/resource.h`에 정의합니다. 같은 리소스를 실행 앱과 렌더링 DLL에 각각 포함하며 `src/UiText.cpp`가 자신이 포함된 모듈에서 지정 언어를 읽습니다. 실행 앱에는 UTF-16, 게임 메뉴에는 UTF-8 문자열을 캐시하여 제공합니다. Windows의 스레드 입력 언어에 의존하지 않도록 `FindResourceExW`에 언어 ID를 명시합니다.

## 사용

1. 게임을 실행합니다.
2. 배포 폴더의 `DaocBrightness.exe` 하나만 복사하여 실행합니다. 별도 DLL이나 이미지 파일을 함께 배포할 필요가 없습니다.
3. 실행 시 관리자 권한 요청을 승인합니다. 관리자 권한으로 실행된 게임의 모듈 조회와 연결에 필요합니다.
4. 대상 PID를 선택하고 연결합니다. 연결 전 목록은 2초마다 자동 갱신되며 새로고침 버튼으로 즉시 갱신할 수 있습니다.
5. 게임에서 **Ctrl+Home**을 눌러 왼쪽 상단 메뉴를 열고 닫습니다.
6. `[-] 값 [+]` 버튼으로 감마, 밝기(노출), 대비, 채도, 밤 / 암부 보정을 조절합니다.
7. 메뉴 마지막의 **기본값 리셋** 버튼은 모든 값을 초기화합니다. 실행 앱에도 리셋 버튼이 있습니다.

`game.dll` / `eden.dll` 실행 파일 이름으로도 PID를 감지합니다. 게임 모듈 조회가 접근 거부로 실패해도 해당 PID를 목록에서 제외하지 않고 권한 오류를 표시합니다.

렌더링 DLL과 코볼트 아이콘, 외부 라이브러리의 라이선스 문구를 EXE 리소스에 내장합니다. 연결할 때 DLL을 `%LOCALAPPDATA%\DaocBrightness\Hook\<SHA256>\DaocBrightnessHook.dll`에 자동으로 추출합니다. 캐시 내용은 내장 데이터와 비교하며, 추출 파일은 연결하는 동안 교체할 수 없도록 읽기 핸들을 유지합니다. 게임에 이미 다른 버전의 렌더링 모듈이 로드된 경우 게임을 다시 실행해야 합니다. DLL 캐시는 게임에서 사용 중일 수 있으므로 앱 종료 시 삭제하지 않습니다. 앱의 **라이선스** 버튼으로 내장 라이선스를 읽을 수 있습니다.

감마 기본값은 1, 밝기는 0, 대비와 채도는 1, 암부 보정은 0입니다. 기본값이면 색 보정 패스를 건너뜁니다. 메뉴를 닫아도 보정은 유지됩니다. 연결 해제하거나 앱을 종료하면 보정을 중지합니다. 앱이 비정상 종료되면 마지막 신호로부터 5초 뒤 보정을 중지합니다. DLL은 게임 종료까지 메모리에 남으며 실행 중 강제로 제거하지 않습니다.

감마, 밝기, 대비, 채도, 암부 보정값은 `%LOCALAPPDATA%\DaocBrightness\settings.ini`에 자동 저장합니다. 마지막 조절 후 약 0.5~1초 안에 저장하며, 연결 해제와 앱 종료 시에도 마지막 값을 저장합니다. 다음 실행 때 불러온 값을 게임 연결 시 적용합니다. 설정은 사용자별로 하나이며 PID가 달라져도 유지됩니다. 기본값 리셋 결과도 저장합니다. 파일이 없으면 기본값으로 시작하고, 손상된 설정이나 저장 실패는 앱 상태에 표시합니다.

암부 보정은 어두운 픽셀을 밝히는 후처리입니다. 게임 시간이나 밤 여부를 자동 판단하지 않으며 광원, 날씨, 서버 상태를 변경하지 않습니다. 게임 UI도 함께 보정됩니다.

## 빌드와 검증

Visual Studio 2022 C++ 데스크톱 개발 도구와 Windows SDK가 필요합니다. 외부 패키지 설치나 별도 DirectX SDK는 필요하지 않습니다.

```powershell
MSBuild.exe DaocBrightness.sln /m /p:Configuration=Release /p:Platform=Win32
.\Release\RenderTests.exe
.\Release\RenderTests.exe --fullscreen
.\Release\RenderTests.exe --hook-dx9 --fullscreen
.\Release\RenderTests.exe --hook-dx10 --fullscreen
```

배포본은 `dist\DaocBrightness.exe` 한 파일입니다. `Release`에는 개발용 DLL과 테스트 실행 파일도 생성되며 배포할 필요가 없습니다. DLL을 먼저 빌드한 후 EXE에 포함합니다. Release 빌드는 최소 크기 최적화(`/O1`, `MinSpace`)를 사용하고 디버그 심볼을 제외합니다. 테스트는 기본값, 색 보정 수식과 실제 DX9 / DX10 GPU 픽셀 비교, 렌더링 상태 복원, 장치 리셋과 버퍼 크기 변경을 확인합니다. 전체 화면 테스트는 일시적으로 독점 화면을 사용하고 종료 후 복귀합니다. 후킹 테스트는 DLL 로딩, 실제 Present 콜백, 리셋 후 재개, 신호 만료와 연결 해제를 확인합니다. 그래픽 장치가 없는 환경에서는 테스트가 실패할 수 있습니다. 실제 게임의 단축키, 마우스 입력, Alt+Tab과 다른 오버레이와의 조합은 별도로 확인해야 합니다.

현재 범위는 표준 DX9 `IDirect3DDevice9::Present`와 DX10 `IDXGISwapChain::Present` 경로입니다. DX9Ex `PresentEx`, 별도 추가 스왑체인, DX11은 지원 범위에 포함하지 않습니다. 연결했지만 프레임이 감지되지 않으면 런처의 상태를 확인하세요. 렌더링 오류가 발생하면 오류 코드를 표시합니다.
